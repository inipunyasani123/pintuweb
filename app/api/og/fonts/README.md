# Font gambar OG

`Inter-SemiBold.ttf` dan `Inter-Regular.ttf` (Inter, Rasmus Andersson) berlisensi SIL Open Font License 1.1.
Sumber: https://fonts.google.com/specimen/Inter. Teks lisensi: https://openfontlicense.org/open-font-license-official-text/

Situs memakai SF Pro bawaan perangkat Apple lewat `-apple-system` (tidak dibundel, karena lisensi Apple tidak
mengizinkan), dan Inter (berkas Google Fonts yang sama, dihost di `public/fonts`) untuk perangkat lain. Gambar OG
dirender di server, jadi memakai Inter.
